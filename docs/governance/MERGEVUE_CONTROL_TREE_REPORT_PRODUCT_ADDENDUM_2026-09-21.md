# 3. NEW CONTROL INVARIANTS

These are report-product invariants and must be carried into the next consolidated Control Tree.

## Invariant RP-1 — Report is projection, not analytical authority

No report, LLM narrative, summary, Brief, PDF, PPTX, or other derivative may create analytical truth not already lawfully established upstream.

## Invariant RP-2 — No report-driven methodology entities

Report UX must not create new methodology states, scores, causal models, confidence models, rankings, or tree nodes merely for presentation convenience.

## Invariant RP-3 — Uncertainty survives projection

Material uncertainty, contradiction, strongest alternative, scope limitation, and lawful falsifier must not be removed where doing so changes decision meaning.

## Invariant RP-4 — No synthetic precision

Do not create synthetic numeric risk/severity/confidence/accuracy metrics unless already defined by governing math/calibration.

## Invariant RP-5 — Commercial boundary does not create analytical truth

FREE/PAID entitlement and display ceilings do not create Decision Gaps, evidence gaps, or analytical conclusions.

## Invariant RP-6 — Purchase remains client-controlled

MergeVue may describe optional additional work but does not pressure purchase using hidden-result mechanics, FOMO, or “pay to see what we found.”

## Invariant RP-7 — Paid means work performed, not answer guaranteed

Paid scope guarantees authorized analysis/evidence/assurance effort, not a determinate/adverse result or formal forecast.

## Invariant RP-8 — Report temporal identity

Every released report is bound to its evidence-through/as-of state and governing methodology/math version.

## Invariant RP-9 — Method changes apply only where materially dependent

No portfolio-wide report rerun is automatic. Review/rerun only reports whose material conclusions depend on the changed governing rule.

## Invariant RP-10 — User historical cutoff is not canonical T0

A user-selected `Analyze as of` date is an evidence cutoff request. Only governing methodology may establish canonical T0/PRE-T0 status.

## Invariant RP-11 — Historical replay is not validation by default

A user-defined replay is not a Prediction Seal, calibrated corpus member, or proof of predictive accuracy unless the full governing historical protocol was actually satisfied.

## Invariant RP-12 — Real/private companies use the same analytical universe

Public/private status changes evidence availability and ingress, not the governing analytical method or report universe.

## Invariant RP-13 — MergeVue remains domain-bounded decision support

Even the $30k Investment Committee Analysis may state decision implications, conditions, dependencies, uncertainties, and controls only inside MergeVue's evidenced domain. It does not issue an autonomous whole-transaction BUY/NO-BUY or PROCEED/STOP verdict.
