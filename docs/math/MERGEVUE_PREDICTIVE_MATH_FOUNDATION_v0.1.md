|---|---|

Отсюда: **цель 77.77% может относиться только к исходу `Y`, а среда — к латентному слою модели.** Это меняет всю метрологию и должно быть зафиксировано до любых вычислений.

## 4. СЛОЙ A — СТАТИЧЕСКАЯ СТРУКТУРА (Хакен, гл. 6)

Якорь: `MergeVue-M&A WORKBENCH/DOWNLOADS/information-and-self-organization-a-macroscopic-approach-to-complex-systems_compress.pdf`, SHA-256 `76ca967ae49ced8677bc7007b7d6dae913cd4d3c05538a3f19a9aaecd7f7ea49`, PDF-стр. 87–94 = печатные 74–80.

### 4.1. Основание метода `[VERIFIED]`

§6.1, дословно:

> «It was assumed that the order parameters could be identified experimentally. In this section we wish to show that our treatment can be generalized in such a way that **no prior knowledge of order parameters is required**. By invoking adequate correlation functions instead, we shall be able to determine the order parameters as well as the enslaved modes and the emerging patterns by means of the formalism.»

Это допускает поиск параметров порядка при подходящей измерительной модели. Отождествление найденных мод с девятью средами MergeVue из цитаты не следует.

### 4.2. Конструкция `[VERIFIED]`

Вектор состояния (6.1): `q = (q₁,…,q_N)`, «whose components are accessible to measurements».

Ограничения — моменты до 4-го порядка (6.2)–(6.5):

```
f_i     = ⟨q_i⟩
f_ij    = ⟨q_i q_j⟩
f_ijk   = ⟨q_i q_j q_k⟩
f_ijkl  = ⟨q_i q_j q_k q_l⟩
```

Максимизация информационной энтропии при этих ограничениях даёт (6.6)–(6.7):

```
P(q) = exp[V(λ, q)]
V(λ, q) = λ₀ + Σ_i λ_i q_i + Σ_ij λ_ij q_i q_j + Σ_ijk λ_ijk q_i q_j q_k + Σ_ijkl λ_ijkl q_i q_j q_k q_l
```

Экстремумы (6.8): `∂V/∂q_i = 0`. Хакен: «In general we expect several extrema whose position we shall denote by q⁰».

Выбор `q⁰` — по максимуму симметрии `V(q⁰+w)`: «this choice means that it is one **without bias**. Only lower symmetry would prefer a specific pattern and thus would introduce a bias.»

### 4.3. Разделение параметров порядка и подчинённых мод

§6.3. Матрица `Λ = (λ_ij)` симметрична (6.16), значит диагонализуема (6.17)–(6.18) ортогональным преобразованием `w_i = Σ_κ a_iκ ξ_κ` с вещественными собственными значениями `λ_κ`. Затем (6.21):

```
λ_κ > 0 ; κ → u,  всего N_u   →  ξ_u = ПАРАМЕТРЫ ПОРЯДКА
λ_κ < 0 ; κ → s,  всего N_s   →  ξ_s = ПОДЧИНЁННЫЕ МОДЫ
```

§6.4, (6.31): `P(ξ) = P(ξ_u) · P(ξ_s | ξ_u)`, и Хакен явно: «P(ξ_s|ξ_u) is a conditional probability… (6.31) represents a special case of the slaving principle».

### 4.4. Отображение на MergeVue — гипотезы, а не установленный мост

Из диагонализации следует `N_u ≤ N_q` для числа положительных собственных направлений. **Число координат порядка не равно автоматически числу дискретных сред.** Несколько режимов/категорий могут описываться одной координатой; одна категория — несколькими. Правило отнесения состояния к среде и проверка его смысла отсутствуют.

| Объект Хакена | Что требуется для связи с MergeVue |
|---|---|
| измеряемые `q_i` | фиксированное кодирование фактов, шкалы и модель ошибок измерения |
| собственные моды `ξ_u` | явное отображение координат/режимов на категориальные среды и критерий проверки |
| подчинённые моды `ξ_s` | определение случайного состояния ресурсов и его пространства |
| `P(ξ_s|ξ_u)` | нормированное условное распределение, а не таблица ресурсных баллов |

Проверенный `ST_Environment_FA_Model_v1.xlsx`, SHA-256 `7d24df222e2ed001eab8fb30f66fe56b9423683ed0eb18bf8c7c3a22f431168a`, содержит 7 344 записи (16 типов × 3 состояния × 9 сред × 17 ресурсов). `README` задаёт F,A в `[1,9]`, индекс F×A в `[1,81]`. Это не условное распределение (6.28)/(6.31), нормированное по пространству подчинённых мод. Совпадение контекста «ресурс при среде» не доказывает тождество объектов. Произвольная нормировка баллов не является обоснованием такого перехода.

Книга прочитана в `Mergevue_launch_corpus/02_ecs_resources_friction/` соседнего каталога проекта; копия в `MergeVue_Corpus_Delta_2026-08-19/xlsx/02_ecs_resources_friction/` имеет тот же хеш. Она использована как предмет P5, а не автоматически повышена до принятой методологической власти.

Предложения E1–E3 прежней редакции не доказаны: ни число сред, ни соответствие нагрузок кодам, ни совпадение распределения с F×A. Необходимые размеры выборки из них пока не выводятся.

## 5. СЛОЙ B — ДИНАМИКА (Хакен, гл. 9)

Якорь: тот же файл, PDF-стр. 138–148 = печатные 125–134.

### 5.1. Оценщик `[VERIFIED]`

§9.1, постановка: «our method can be considered as a tool to derive the underlying deterministic and fluctuating forces from experimental data». Основание — принцип максимума калибра Джейнса.

Ограничения — **первые два условных момента** (9.5)–(9.7), (9.21)–(9.22):

```
f₁,i   = ⟨q_i(t+τ)⟩ | q(t)
f₂,ik  = ⟨q_i(t+τ) q_k(t+τ)⟩ | q(t)
```

Главный результат (9.19), одномерный случай:

```
P(q_{i+τ} | q_i) = √(1/(2πτG)) · exp{ −(1/(2τG)) [ q_{i+τ} − q_i − τK(q_i) ]² }
```

Многомерно: (9.23)–(9.31), `G_kl[q(t)]` из (9.30), `K_i[q(t)]` из (9.31).

### 5.2. Что это означает операционально `[DERIVED]`

(9.19) — **гауссова переходная плотность со сносом K и диффузией G**. Оценка K и G из данных = регрессия приращения `Δq` на состояние `q`. Это задача условной оценки, сложность и точность которой зависят от размерности, панели, регулярности и модели шума; её разрешимость на данном корпусе не установлена.

Принципиально: динамике достаточно **первого и второго** условных моментов. Четвёртый порядок гл. 6 нужен только для статического потенциала. Это уменьшает порядок используемых моментов, но само по себе не даёт меньшего требуемого размера выборки: условные моменты являются функциями состояния.

### 5.3. Требование к данным `[COMPUTED C-10]`

Гл. 9 предполагает марковость (9.3) и стационарность. Минимум: ≥2 момента времени на сделку для `K`; ≥3 для любой проверки марковости.

**Текущий корпус даёт одну точку (T0) на сделку. `K` и `G` не идентифицированы.** Слой B на имеющихся данных неисполним.

## 6. СЛОЙ C — ДОПУСТИМОСТЬ УЛИКИ (Чернавский, гл. 1)

Якорь: `Структурная Типология 2024/Книги разные/Философия/08 Дополнительная литература/Чернавский Д.С. Синергетика и информация 2001.doc` (OLE, UTF-16LE).

### 6.1. Критерий допустимости `[VERIFIED]`

Определение (Q), по Кастлеру:

> «Информация есть запомненный выбор одного варианта из нескольких возможных и равноправных.»

и различение:

> «выбор может и не запоминаться… Такой выбор будем называть **микроинформацией**. Запомненный выбор… будем называть **макроинформацией**. Во всех информационных процессах используется макроинформация.»

**Предложение A1:** использовать документально зафиксированные факты согласно проектным правилам допуска. Оно не выводится как «тогда и только тогда» из определения информации: записанное мнение или ретроспективный нарратив тоже могут быть запомнены. Допустимость, временная чистота и истинность требуют отдельных проектных проверок; цитата их не заменяет.

### 6.2. Определение среды `[VERIFIED]`

> «Пример **условной информации** — код… Кодом называется соответствие между условными символами и реальными предметами. …**Ценной кодовая информация может быть только если ею владеет несколько объектов (человек), то есть эта информация связана с коллективным поведением.**»

**Гипотеза A2:** общие коды могут быть частью измерительной модели среды. Определение среды как кода и измеримость пересечения кодов не следуют из цитаты без операционализации и проверки.

### 6.3. Вес улики `[VERIFIED]` + `[COMPUTED C-11]`

`V = log₂(P/p)` (1.3); мера Корогодина `V_K = (P−p)/(1−p)` (лежит в `[0,1]` только при `0≤p≤P≤1`, `p<1`) (1.4), где `p` — вероятность достижения цели **до** получения информации, `P` — после. «Предварительная осведомлённость называется **тезаурусом**.»

**Предложение A3:** рассматривать `V` как изменение вероятности достижения заранее определённой цели. Это пока не операциональный вес факта: нужно определить и оценить `p`, `P`, зависимости между фактами и наблюдаемый критерий правильной идентификации среды. На корпусе такой ground truth не установлен.

При гипотетическом равномерном приоре `p=1/9`, `V_max=log₂9=3.1699` бит. `V≤0` означает отсутствие прироста или контрсвидетельство относительно указанной цели; **это не правило удаления контрсвидетельств**.

### 6.4. Рецепция vs генерация `[VERIFIED]`

> «**Рецепция** информации — выбор, продиктованный свыше… **Генерация** информации — выбор, сделанный случайно, без подсказки извне.»

Формальный аналог различения Вераксы: личность генерирует норму, псевдо-личность рецептирует. Это возможная содержательная аналогия; валидированный критерий типа субъектности из неё не выведен.

Расчёты относятся к `θ*=7/9`. Буквальные `77.77%=0.7777` отличаются; выбор публичной метрики и порога должен быть явно записан в печати. Здесь сохраняется прежняя расчётная конвенция, а не принимается новое продуктовое решение.

### ТЕОРЕМА 1 — максимум CP при десяти iid испытаниях `[C-02]`

Для независимых Bernoulli-индикаторов **правильности прогноза** с общей вероятностью θ, фиксированным n и заранее определённым правилом оценивания односторонняя 95% нижняя граница CP равна `Beta⁻¹(0.05;k,n−k+1)` (при k=0 — 0). Она возрастает по k. При k=n максимум равен `0.05^(1/n)`.

При n=10 он составляет **0.741134 < 7/9**. Следовательно, данный точный биномиальный критерий не сертифицирует θ>7/9 даже при 10/10. Это не теорема о любых оценщиках, априорной информации, конечном перечне из десяти уже оценённых сделок или иных метриках. 8/10=80% — допустимое описательное значение; оно не является 95% гарантией для будущей популяции.

| результат | односторонняя 95% LCB | двусторонний 95% ДИ |
|---|---|---|
| 8/10 | 0.4931 | [0.4439, 0.9748] |
| 9/10 | 0.6058 | [0.5550, 0.9975] |
| 10/10 | 0.7411 | [0.6915, 1.0000] |

Независимость сделок без общей вероятности правильности не устанавливает эту биномиальную модель. Переобучение и селекция оцениваемых наблюдений также требуют отдельного обоснования.

### ТЕОРЕМА 2 — только размерностная граница `[C-09]`, `[C-13]`

Для симметричной `Λ∈ℝ^(N_q×N_q)` число положительных собственных направлений удовлетворяет `N_u≤N_q`. Это следует из размерности матрицы.

**Отозван вывод `N_q≤4` при 20 наблюдениях.** Число коэффициентов полинома второго порядка `N_q+N_q(N_q+1)/2` вычислено верно, но условие «наблюдений больше параметров» не является общим условием идентифицируемости распределения. Одно наблюдение здесь — вектор.

Контрпример: Gaussian/MaxEnt-модель в ℝ⁹ имеет 54 параметра среднего и ковариации. При 20 независимых векторах общего положения ковариация положительно определена и MLE существует; `[C-09]` воспроизводит пример полного ранга 9. Идентифицируемость семейства, существование оценки и её точность — разные вопросы.

Кроме того, чисто квадратичный нормируемый потенциал на ℝ^d требует отрицательно определённой квадратичной части. Положительные неустойчивые моды Хакена требуют стабилизирующих старших членов или явно ограниченной области. Поэтому квадратичную Gaussian-модель нельзя одновременно считать доказанным механизмом девяти неустойчивых сред.

Пороги **55 сторон, 28/36 сделок и непроверяемость девяти сред «в принципе» не доказаны** прежним подсчётом. Их удаление не устанавливает достаточность N=10.

### ТЕОРЕМА 3 — точная дробь `[C-01]`

Для положительного целого n существует k с `k/n=7/9` тогда и только тогда, когда `9|n`. Для буквального `0.7777=7777/10000` соответствующее условие — `10000|n`. Требование «минимум» не требует точного равенства: 8/10 превышает оба порога.

### ТЕОРЕМА 4 — константный базис `[C-06]`

Если `p=P(Y=1)`, точность заранее выбранного соответствующего константного предиктора — p или 1−p; лучший популяционный константный базис имеет точность `max(p,1−p)`. При `max(p,1−p)≥7/9` попадание в цель не доказывает преимуществ модели над базисом.

Фактическая база каждой Y неизвестна. Общая статистика «провала M&A» не подставляется вместо неё. Сбалансированная точность, Brier, AUC и lift — различные цели, а не взаимозаменяемые варианты биномиальной доли попаданий. Выбор остаётся Owner-решением.

### ТЕОРЕМА 5 — конформное покрытие и полный набор `[C-08]`, `[C-15]`

Пусть калибровочные и новая тестовая точки обменимы относительно одного score, а предиктор зафиксирован без использования калибровочных исходов. При `k=ceil((n_cal+1)(1−α))` берётся k-я порядковая статистика score; если `k>n_cal`, берётся `q̂=+∞`.

Множество `C(x)={y:s(x,y)≤q̂}` имеет маргинальное покрытие ≥1−α. При n_cal=10 наибольший **конечный эмпирический** порог — максимум десяти scores, дающий нижнюю гарантию 10/11. При α<1/11 результатом становится всё пространство исходов с покрытием 100%, а не математическая невозможность.

Гарантия не является точечной точностью, условным покрытием конкретного типа/эпохи или 95% нижней границей качества фиксированного калиброванного набора. Все десять сделок могут быть калибровочными только при независимо заданном предикторе; их нельзя одновременно использовать для его подгонки и обычной split-калибровки. При разделении корпуса в формулу входит фактическое n_cal.

### Мощность фиксированного биномиального плана `[C-03]`, `[C-04]`

`k_req(n)=min{k:P_(7/9)(Bin(n,7/9)≥k)<0.05}`; мощность при θ равна `P_θ(Bin(n,θ)≥k_req)`. Из-за дискретности она не монотонна по n.

| iid испытания n | k_req | мощность при θ=0.90 |
|---|---|---|
| 12 | 12 | 0.2824 |
| 20 | 19 | 0.3917 |
| 36 | 33 | 0.5085 |
| 40 | 36 | 0.6290 |

В пределах сканирования до n=1200 устойчивые пороги 80% мощности: θ=.95 → 33, θ=.90 → 68, θ=.85 → 203. Для θ=.80 скан до 1200 недостаточен: при n=2200 мощность **0.810754**. Прежнее «не достигается никогда» неверно; при фиксированном θ>7/9 мощность стремится к единице.

### Кластеризация и смена уровня наблюдения `[C-05]`, `[C-19]`, `[C-22]`

При G независимых равных кластерах размера m, общей Bernoulli-дисперсии и попарной корреляции **индикаторов правильности** ρ:

`Var(mean X)=θ(1−θ)[1+(m−1)ρ]/(Gm)`.

`n_eff=Gm/[1+(m−1)ρ]` — эквивалент по дисперсии, не число независимых Bernoulli-испытаний. Для неравных размеров и той же общей дисперсии/ρ: `n_eff=M²/[M+ρΣ_d m_d(m_d−1)]`, `M=Σ_d m_d`. Подставлять округлённое n_eff в CP как точный тест нельзя. Корреляция самих исходов Y не обязана равняться корреляции ошибок прогноза.

Контрпример `[C-22]`: семь независимых кластеров по восемь лиц; число правильных прогнозов S равно 2,3,8 с вероятностями `(100,312,803)/1215`; правильные лица выбираются равномерно. Тогда θ=7/9, ρ=1/2 точно. Подстановка `floor(n_eff)=12` сертифицирует цель при 56/56, поскольку LCB=.779078. Но вероятность такого ложного сертификата `(803/1215)^7=.05507758>.05`. Ошибка сохраняется при **известной** ρ.

Альтернативы требуют отдельного дизайна: анализ независимых кластерных итогов с конечновыборочной границей для соответствующего estimand либо явно специфицированная и проверенная модель внутрикластерного распределения. Малокластерные асимптотические интервалы сами по себе точности 95% не гарантируют. Здесь новый кластерный сертификатор не принят.

## 13. ПОСЛЕДОВАТЕЛЬНЫЙ ПРОТОКОЛ

### 13.1. Разделение операций

Перефит и повторная проверка статистической гипотезы — разные операции. Отсутствие доступа к будущим меткам устраняет прямую утечку, но не доказывает общую iid-точность или перенос на будущий рынок.

### 13.2. Преквенциальная оценка

`обучиться на прошлом → запечатать прогнозы следующего блока → раскрыть исходы разрешённым актором → оценить → добавить в обучение`.

Записываются out-of-sample ошибки **процедуры обучения и прогнозирования**, а не автоматически качество последней версии модели. Правила преобразования фактов и Y также должны быть зафиксированы без будущих исходов. Запуск этой процедуры не авторизован данным исправлением.

### 13.3. Повторный фиксированный CP `[C-16]`

При iid θ=7/9 проверка CP каждые пять испытаний до n=80 даёт точную вероятность хотя бы одного ложного срабатывания **0.119019**. Прежняя симуляция .1182 согласуется с этим; проблема подглядывания реальна. Скрипт теперь считает её рекурсией по состояниям (n,k), без Monte Carlo.

### 13.4. Исправленный односторонний e-процесс `[C-17]`

Нулевая гипотеза для адаптивного потока: `E[X_t|F_(t−1)]≤θ₀` для каждого t, где X_t — правильность заранее запечатанного прогноза. Это сильнее ограничения на одну среднюю точность за весь период.

Выбирается заранее равномерная смесь альтернатив `q∈(θ₀,1)`:

```
E_n = integral_(θ₀)^1 q^k(1−q)^(n−k) dq
      / [(1−θ₀) θ₀^k (1−θ₀)^(n−k)]
    = B(k+1,n−k+1) [1−I_(θ₀)(k+1,n−k+1)]
      / [(1−θ₀) θ₀^k (1−θ₀)^(n−k)]
```

Для фиксированного q≥θ₀ условное ожидание множителя равно `p_t q/θ₀+(1−p_t)(1−q)/(1−θ₀)≤1` при p_t≤θ₀. Интегрирование сохраняет неотрицательный супермартингал с E₀=1. По Виллю `P_H0(sup_n E_n≥20)≤.05`.

**Прежняя смесь Beta(1,1) на [0,1] отозвана для односторонней задачи:** после трёх ошибок она давала E=22.78125, отвергая θ≤7/9 в неверную сторону; при θ=0 срабатывала с вероятностью 1. Исправленная смесь даёт при 0/3 E=.25.

### 13.5. Цена зависит от теста, а не только от частоты проверок

Безошибочная серия пересекает 20 при **n=18** для исправленной равномерной смеси. Предварительно выбранная точечная альтернатива q=1 пересекает порог при **n=12**, но обнуляет E после первой ошибки. Прежние 25 испытаний — свойство другой смеси, не универсальная цена anytime-valid контроля.

Для выбранного корректного e-процесса все моменты проверки покрываются одной границей. Операционный шаг +5 допустим; изменение альтернатив/метрики после просмотра данных не становится бесплатным. Bonferroni и иные заранее заданные планы имеют иной компромисс мощности; универсального порядка «дороже смеси» нет.

### 13.6. Мощность и дрейф `[C-18]`

Скрипт вычисляет точную вероятность пересечения исправленной границы к каждому n для iid альтернатив θ=.85/.90/.95. Это расчёт мощности данного теста, а не доказательство iid для изменяющейся процедуры. Фиксированная мощность при θ=.90: n=36 → .508511, n=40 → .629018. Прежние таблицы последовательной мощности и вывод о достаточности 50–80 сделок отозваны.

| n_max | θ=.85 | θ=.90 | θ=.95 |
|---|---|---|---|
| 25 | .054 | .150 | .397 |
| 36 | .087 | .255 | .623 |
| 50 | .139 | .420 | .855 |
| 80 | .241 | .694 | .988 |
| 120 | .345 | .868 | 1.000 |

Значения округлены до трёх знаков; 1.000 не означает математически единичную вероятность. Это iid-расчёт данного теста, не сертификат размера корпуса.


Adaptive conformal inference — отдельный механизм с другой целью (долгосрочная частота покрытия). Он не следует из e-процесса и не закрывает P4.5 на десяти сделках.

### 13.7. P8 — дополнительные методы и пределы их смысла

- Байесовский расчёт с iid Bernoulli likelihood и гипотетическими 10/10: `P(θ>7/9|data)=.936990` при Beta(1,1), `.950992` при Beta(2,1). Более сильный результат требует заранее обоснованного приора; оснований принять Beta(2,1) в проекте нет. Это posterior probability, не частотная 95% гарантия.
- Точное парное сравнение с базисом/перестановочный тест может отвечать на вопрос о преимуществе при малой выборке, если обоснованы его обменимость/рандомизация. Оно не сертифицирует автоматически абсолютную точность ≥7/9. Для зависимых лиц единица перестановки и нуль должны учитывать сделку.
- Более информативные данные внутри сделки могут быть полезны при явной измерительной и вероятностной модели. Само увеличение номинального числа лиц не является доказательством.
