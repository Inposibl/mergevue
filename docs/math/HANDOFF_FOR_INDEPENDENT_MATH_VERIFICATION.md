## 5. ПОСЛЕДОВАТЕЛЬНЫЙ ПРОТОКОЛ

Исправленная смесь заранее равномерна по q∈(θ₀,1):

`E_n = integral_(θ₀)^1 q^k(1−q)^(n−k)dq / [(1−θ₀)θ₀^k(1−θ₀)^(n−k)]`.

Нуль: E[X_t|past]≤θ₀ для каждого t. Для каждого фиксированного q≥θ₀ ожидаемый множитель ≤1; интеграл — неотрицательный супермартингал, E₀=1. Вилль разрешает проверять E_n≥20 в любой момент. Это не тест произвольной средней точности за период.

Проверить отрицательный контроль: старая смесь по [0,1] давала E(0,3)=22.78125; новая даёт .25. Безошибочная серия: новая равномерная смесь пересекает 20 на n=18. Предзаданная точечная альтернатива q=1 пересекает на n=12, но обнуляется после первой ошибки. Число 25 не универсальная цена мониторинга.

Преквенциальная оценка относится к процедуре обучения/прогнозирования; отсутствие прямой утечки не доказывает iid и перенос на продукт. Мощность в C-18 рассчитана под iid альтернативами, отдельно от валидности условного нуля.

**F2. Оговорка Т1 «без универсального запрета иных методов» верна, но безымянна; конкретный экземпляр существует.**

Для нерандомизированных монотонных процедур граница `0.741134` действительно максимальна: наименьшая область отвержения `{K=10}` даёт `sup{θ : θ¹⁰ ≤ .05} = .05^{1/10}`. Однако **рандомизированный точный тест** — отвергать при `K=10` с вероятностью `γ` — валиден и даёт `LCB = (0.05/γ)^{1/10}`. При `γ ≤ 0.617184` граница превышает 7/9.

```python
T=7/9; A=0.05; n=10
for g in (1.0,0.7,0.5,0.3):
    print(g, (A/g)**(1/n), (A/g)**(1/n) > T)
# 1.0 0.741134 False | 0.7 0.768046 False | 0.5 0.794328 True | 0.3 0.835959 True
print("критическая gamma =", A/(T**n))   # 0.617184
```

Расчёт намеренно **не внесён** в `verify_math.py`, чтобы не изменять опечатанные артефакты; врезка воспроизводима отдельно.

Процедура практически неприменима: решение о публикации результата принимается подбрасыванием монеты. Именно поэтому её стоит назвать — она превращает абстрактную оговорку в ограниченное утверждение и вынуждает документ сформулировать то, что сейчас отсутствует: **«сертифицируемо» должно означать «сертифицируемо процедурой, которую заказчик согласится принять»**. Это нормативное требование к допустимому классу процедур, а не математическое, и его отсутствие — брешь в §7 базы.

*Предмет проверки:* корректность расчёта; и следует ли зафиксировать явное ограничение класса допустимых процедур (нерандомизированные, монотонные, с предобъявленным планом), без которого Т1 не является границей.

**F3. Надбавка в безошибочной серии относится только к конкретно сравненным процедурам.**

При θ₀=7/9 и α=.05 сохранено точное сравнение из §5 handoff и C-17:

- фиксированный односторонний CP: порог при безошибочном результате — **n=12**;
- e-процесс с заранее заданной точечной альтернативой **q=1**: первое пересечение E_n≥20 — **n=12**;
- равномерная односторонняя смесь по **q∈(θ₀,1)**: первое пересечение E_n≥20 — **n=18**.

Формулировка **«от 0 до +6 испытаний» (`0 to +6 trials`) относится только к этим конкретно сравненным процедурам** относительно фиксированного CP n=12: для q=1 добавка равна 0, для указанной равномерной смеси — +6. Это **не универсальная граница по всем допустимым односторонним смесям** и не общий результат о цене anytime-validity.

Поведение остановки зависит от заранее заданной альтернативы / смеси. Точечный e-процесс q=1 обнуляется после первой ошибки; равномерная смесь сохраняет положительное значение, что само по себе не гарантирует пересечения порога. Сравнение этих двух свойств не устанавливает универсальную цену устойчивости и не выбирает предпочтительную смесь.

*Предмет проверки CORR1:* сохранены ли пороги 12/12/18, ограничено ли `0 to +6 trials` названными процедурами и отсутствует ли выбор предпочтительной смеси. Продуктовое решение о допустимой процедуре этим сравнением не принимается.
