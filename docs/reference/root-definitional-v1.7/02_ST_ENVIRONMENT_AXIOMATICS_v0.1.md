## 1. ПРИМИТИВЫ

### 1.1 Стадии развития

Совмещение стадий интеллектуального развития Ж. Пиаже и темпераментов Д. Кейрси. Упорядочены:

```
SP(1) < SJ(2) < NT(3) < NF(4)
```

| Стадия | Происхождение | Среда общения |
|---|---|---|
| SP(1) | игровая стадия | ориентация на ощущения и три базовых желания: обладать, избежать, напасть |
| SJ(2) | стадия конкретных операций | договорённость о способах достижения практического результата |
| NT(3) | стадия формальных операций | рационально-интуитивная, создание сложных семантических форм |
| NF(4) | стадия формирования мировоззрения | холистически-ценностная, «понять весь мир, чтобы найти в нём своё место» |

### 1.2 Компоненты

S-стадии расщепляются по предпочтению принятия решения. N-стадии разрешены изначально.

| Компонент | Стадия | Предпочтение |
|---|---|---|
| STP | 1 | T |
| SFP | 1 | F |
| STJ | 2 | T |
| SFJ | 2 | F |
| NT | 3 | T |
| NF | 4 | F |

### 1.3 Правило масштаба

Настоящая аксиоматика описывает **среды взаимодействия**. Явления личного масштаба, управляемые той же переменной институциональной оболочки — например, переход человека между средами при неизменных влечениях, — относятся к актор-слою (`ST_NS_Actor_Position`, Module B; уровни освоения НС и три роли из «Теории Нормативная ситуация») и в настоящем документе не формализуются.

Общий корень обоих масштабов формулируется так: **оболочка определяет, где лежит последствие — на участнике либо нигде.** Утверждение масштабно-нейтрально. T4c есть его применение к средам; актор-слой есть его применение к людям.

Иллюстрация личного масштаба, приводимая автором — хулиган, становящийся полицейским или военным, — демонстрирует переменную оболочки, но **для T4c ненормативна**: это перемещение человека между двумя существующими средами, а не инверсия одной среды.

## 2. АКСИОМЫ

**A1 · Пара.**
Среда взаимодействия есть упорядоченная пара **(Феномен / Сущность)**.
Феномен — стадия, которую среда проецирует вовне.
Сущность — стадия, которая фактически управляет совместной деятельностью.

> Источник: `[СТ-7, ¶615]` — «Если **сущность** среды SJ/SP выражается через SFP, то ее **внешнее (феноменологическое) проявление** принимает форму SFJ».

**A2 · Отсутствие чистых стадий.**
Чистых стадий не бывает. Всякая реальная среда есть пара.

> Источник: `[СТ-6]` — «не существует абсолютно „чистых“ темпераментов»; стадии не рассматриваются как строго изолированные.

**A3 · Источник нормы.**
Новую норму способен создать только субъект на рефлексивном уровне освоения нормативной ситуации.

> Источник: `[НС, с. 9]` — на рефлексивном уровне «человек уже способен создавать новые культурные нормы, правила и интегрировать их в существующую систему»; `[НС, с. 14]` — «Личностью становится только тот субъект НС, который является создателем новых социальных норм».

**A4 · Последовательность уровней.**
Уровни освоения НС проходятся последовательно: субъект не может преодолеть их скачкообразно.

> Источник: `[НС, с. 9]` — «Последовательные уровни освоения, которые субъект **не может скачкообразно преодолеть**».

> **Ослаблено в v1.7.** До v1.7 A4 читалась как «субъект не может оперировать правилами выше своего уровня освоения НС; оперировать правилами ниже своего уровня он может». Эта формулировка **сильнее источника**: источник утверждает непрерывность восхождения по уровням, а не запрет на оперирование правилами вышестоящего уровня и не разрешение на оперирование нижестоящими.
>
> Прежняя формулировка выделена в отдельную гипотезу **H-A4**, не входящую в аксиоматику:
>
> **H-A4 · Операционная асимметрия уровней (ГИПОТЕЗА, не аксиома).** Субъект не оперирует правилами уровня выше собственного; правилами уровня ниже — оперирует.
>
> Всё, что ранее выводилось «по A4», отныне выводится по **H-A4** и наследует её статус гипотезы. Это затрагивает T7 и, через T7, часть обоснования D2.

## 3. ПРАВИЛА ОТБОРА

**R1 · Разность стадий.**
Феномен и Сущность принадлежат разным стадиям.

**R2 · Сохранение предпочтения решения.**
Если хотя бы один компонент относится к S-стадии, оба компонента разделяют T либо оба F. Среда инвертирует стадию, но не способ принятия решения.

**R3 · Запрет скрытой развитости.**
Если Феномен есть S, Сущность не может быть N.

**R4 · Снижение только внутри S-слоя.**
Сущность может стоять выше Феномена по стадии только когда оба компонента относятся к S-стадиям.

## 4. СЛЕДСТВИЯ

### T1 · Ровно девять сред

Отсев по шагам, машинная проверка перечислением:

| Шаг | Осталось | Отсеяно |
|---|---|---|
| **R1** разные стадии | **26** | — |
| **R2** сохранение T/F | **14** | 12 пар со смешанным T/F при S-компоненте |
| **R3** запрет скрытой развитости | **10** | `STP/NT` · `SFP/NF` · `STJ/NT` · `SFJ/NF` |
| **R4** снижение только в S-слое | **9** | `NT/NF` |

Остаётся **девять**:

```
NF/NT · NT/STJ · NT/STP · NF/SFJ · NF/SFP
STJ/STP · SFJ/SFP · STP/STJ · SFP/SFJ
```

*Следует механически из R1–R4. Подтверждения автора не требует.*

### T2 · Снижение есть сигнатура вербовки

Нисходящих пар ровно две — **STP/STJ** и **SFP/SFJ**. Обе имеют ресурсные формулы вовлечения и извлечения. Среда представляется свободнее, чем есть, потому что её аудитория — субъекты импульсивного и полевого уровней освоения НС, не различающие подмену.

### T3 · Разрыв как мера

> **Разделено в v1.7.** До v1.7 T3 одним предложением переходил от арифметики к утверждению о расходе энергии. Арифметика корректна; переход — нет. Ниже T3 разделён на формальную часть **T3-F** и эмпирическую гипотезу **T3-H**. Гипотеза не выводится из формальной части и не наследует её статус.

#### T3-F · ФОРМАЛЬНАЯ ЧАСТЬ · порядковая структурная дистанция

```
Δ = |стадия(Феномен) − стадия(Сущность)| ∈ {1, 2, 3}
```

Δ есть **порядковая структурная дистанция** между заявленной и действующей стадией. Величина вычисляется из кода. Новых весов не вводится.

Δ **не является** мерой расхода энергии, доли энергии или количества энергии, затрачиваемой на поддержание иллюзии. Никакой энергетической функции здесь не определяется.

#### T3-H · ЭМПИРИЧЕСКАЯ ГИПОТЕЗА · дисбаланс и энтропия

**Гипотеза.** Большей структурной дистанции Δ соответствует более высокий дисбаланс между внешне заявленными ценностями среды и её фактическим воздействием, вплоть до саморазрушения среды на максимуме Δ.

Опора — авторская формулировка о среде `NF/SFP` (Δ=3), `[СТ-6, с. 20]`:

> «систему с высокой степенью энтропии»
>
> «экспоненциальное нарастание дисбаланса между внешне заявленными ценностями среды и её фактическим воздействием на человека»

Источник характеризует **одну среду максимального Δ**, а не монотонную зависимость по всем трём значениям Δ. Обобщение на весь диапазон `{1,2,3}` есть шаг транскриптора, подтверждённый автором как гипотеза, и эмпирически не установлено.

Порядковая иллюстрация, сохраняемая как авторская характеристика, а не как измерение:

- **Δ=1** — среда делает примерно то, что показывает
- **Δ=2** — война либо утрата контроля
- **Δ=3** — максимум: трата под благовидным мотивом

**Статус.** `EMPIRICAL HYPOTHESIS / NOT ESTABLISHED`. T3-H требует калибровки на корпусе кейсов и в корневом аудите вердикта об истинности не получает.

### T4 · Условная система переходов между средами

> **Статус в v1.2.** В v1.0 T4 был единым правилом и содержал дефект: записанное правило не порождало первый шаг заявленной F-линии. В v1.1 переведён в `ОТКРЫТО`. В v1.2 автор разделил T4 на три различных механизма — T4a, T4b, T4c — и подтвердил каждый.
>
> **Статус в v1.7 — контролирующее уточнение Владельца.** T4 есть **условная система переходов**. Каноническая форма:
>
> ```
> Среда + триггер → Среда
> ```
>
> Утверждение v1.6 `механизмы не пересекаются ни на одной среде из девяти` **удалено как ложное**. Оно было получено разбором вырождения T4a/T4c на нисходящих парах и неправомерно распространено на все три механизма. Независимый аудит v1.6 предъявил контрпример: `NF/NT` получает определённый результат и по T4a, и по T4b.
>
> Владелец уточняет: это **не дефект пересечения**. Два перехода из `NF/NT` законны, поскольку возникают при разных триггерах и не являются конкурирующими выходами одного механизма.

Переход среды в другую среду происходит несколькими различными способами. Они различаются по причине, темпу и по тому, что именно меняется в паре. Триггер входит в переход как обязательная составляющая: без указания триггера запись `Среда → Среда` неполна.

#### Правило применимости

Одна и та же исходная среда может допускать **более одного законного перехода**, если триггеры различны. Система переходов **не является функцией** из девяти сред в девять сред.

**Приоритет между T4a, T4b и T4c не устанавливается.** Ни автор, ни первичный источник его не задают; транскриптор не вправе его изобрести. Там, где к одной среде применимы два механизма, исход определяется тем, какой триггер фактически наступил, и в отсутствие сведений о триггере остаётся неопределённым.

> **Что это означает для проверки.** Верификатор проверяет: (1) область каждого механизма; (2) замыкание каждого механизма внутри его области; (3) что триггеры механизмов различны и записаны; (4) что пакет не заявляет приоритета и не заявляет отсутствия пересечения. Верификатор **не должен** трактовать наличие двух законных переходов из одной среды как противоречие.

#### T4a · Соскальзывание

Внутренний структурный распад.

**Триггер.** Эндогенный. Дискретного внешнего институционального события **не требуется**; переход происходит сам, изнутри, по мере распада.

**Правило.** Сущность опускается на одну стадию; бывшая Сущность становится Феноменом; R2 сохраняется.

**Область применения.** Восходящие пары — где Сущность ниже Феномена по стадии.

| Среда | Преемник |
|---|---|
| NF/NT | NT/STJ |
| NT/STJ | STJ/STP |
| NF/SFJ | SFJ/SFP |
| NT/STP · NF/SFP · STJ/STP · SFJ/SFP | терминал — Сущность на стадии 1 |

Независимое свидетельство среднего звена: `ENVIRONMENT_NS` фиксирует «guide warns NT/STJ→STJ/STP is the most common failure mode».

#### T4b · Вытеснение

Демографическое замещение. Не структурный распад, а занятие позиции численностью.

**Триггер.** Долгогоризонтное изменение состава популяции внутри среды. Не дискретное событие и не сделка.

**Темп.** Десятилетия и более.

**Основание — первичный источник.** Распределение темпераментов в популяции, `[КЕЙРСИ, с. 5]`:

> «самый часто встречающийся типологический темперамент, это „Стражники“ — SJ-еи. **Порядка 50%** от общей популяции человечества. „Ремесленники“, SP — **около 27%**, „Рационалисты“, NT — **около 10%** и „Идеалистов“ NF — в популяции **порядка 13%**»

Следующее предложение источника, `[КЕЙРСИ, сс. 5–6]` (предложение пересекает разрыв страниц):

> «именно SJ-еи, как **тотальное большинство**, определяют интенсивность и направление движения нашей цивилизации, а все другие типы темпераментов служат им в достижении их целей»

**Правило (формализовано в v1.7).** Феномен удерживается. Сущность вытесняется **максимальным по численности** слоем, совместимым с удержанным Феноменом.

```
1. слой  := argmax { SJ .50 , SP .27 , NF .13 , NT .10 }
2. ветвь := по R2, от удержанного Феномена
             удержан T-Феномен → совместимая ветвь SJ-слоя = STJ
             удержан F-Феномен → совместимая ветвь SJ-слоя = SFJ
3. если получившаяся пара нарушает R1 → терминал
   иначе                              → переход по T4b допустим
```

> **Что исправлено в v1.7.** До v1.7 правило гласило «Сущность вытесняется численно преобладающим слоем». Формулировка не задавала оператор выбора: буквальное чтение допускало любой слой, превосходящий вытесняемый по численности, и потому порождало отсутствующий в таблице переход `NF/NT → NF/SFP` (SFP ≈ 27 % превосходит NT ≈ 10 % и совместим по F). Оператор `argmax` устраняет эту ветвь: SFP не является максимумом. Оператор взят не из соображений удобства, а из процитированной формулировки источника о **тотальном большинстве**.

| Среда | Преемник | Что вытесняется |
|---|---|---|
| NF/NT | NF/SFJ | NT (10%) вытесняется SFJ — максимальным слоем, ветвь F по удержанному Феномену NF |
| NT/STP | NT/STJ | STP (27%) вытесняется STJ — максимальным слоем, ветвь T по удержанному Феномену NT |
| NF/SFP | NF/SFJ | SFP (27%) вытесняется SFJ — максимальным слоем, ветвь F по удержанному Феномену NF |
| остальные | терминал | Сущность уже принадлежит SJ-слою либо результат нарушает R1 |

**Правило равенства максимумов.**

```
НЕЕДИНСТВЕННЫЙ ARGMAX → UNRESOLVED / ДЕТЕРМИНИРОВАННОГО ПРЕЕМНИКА ПО T4b НЕТ
```

Содержательное правило разрешения ничьей **не вводится**: первичный источник его не задаёт, а изобретать его транскриптор не вправе. При заявленных долях `50 / 27 / 13 / 10` максимум единствен, поэтому данная ветвь **недостижима** и на текущие девять сред не влияет. Она записана на случай последующего уточнения долей.

> **Замечание к проверке.** Два перехода — `NT/STP → NT/STJ` и `NF/SFP → NF/SFJ` — суть механическое замыкание подтверждённого правила и в исходной формулировке автора не перечислялись. Верификатору надлежит воспроизвести замыкание независимо, а также независимо проверить, что `argmax` не порождает ветви `NF/NT → NF/SFP`.

> **Границы источниковой опоры.** Источник даёт доли и утверждение о тотальном большинстве. Источник **не формулирует** T4b как механизм перехода сред и не содержит оператора `argmax` в математическом виде. Доли — `PRIMARY SOURCE STATEMENT`; прочтение «максимальный слой» — `OWNER INTERPRETATION`; запись через `argmax` — `FORMALIZATION`. Утверждение, что вытеснение фактически происходит именно так и именно за десятилетия, остаётся `EMPIRICAL HYPOTHESIS`.

#### T4c · Инверсия обёртки · двунаправленная

Компоненты пары не меняются. Меняются их позиции.

**Управляющая переменная — наличие институциональной оболочки.**

**Триггер.** Дискретное изменение институциональной оболочки — её приобретение либо утрата. В отличие от T4a и T4b, триггер здесь событийный и в принципе датируемый.

**Приобретение оболочки** — нисходящая пара становится восходящей. Прежняя Сущность поднимается в Феномен и превращается из того, что бьёт, в то, что укрывает. Вербовочное давление снимается. Последствие уходит от участника.

```
STP/STJ → STJ/STP        SFP/SFJ → SFJ/SFP
```

**Утрата оболочки** — восходящая становится нисходящей. Феномен перестаёт укрывать, прежняя Сущность возвращается в позицию Феномена, вербовочная форма восстанавливается. Последствие возвращается к участнику.

```
STJ/STP → STP/STJ        SFJ/SFP → SFP/SFJ
```

Δ и R2 неизменны в обе стороны.

**Наблюдаемый маркер направления — где лежит последствие:** уходит от участника к никому, либо возвращается от никого к участнику.

**Связь с T11.** Приобретение оболочки превращает спроектированный разрыв в унаследованный: среда перестаёт знать, что она такое. Утрата возвращает знание. `ENV_NS_SCHEMA` фиксирует о нисходящей STP/STJ: «participation is knowing».

**Граница масштаба.** T4c описывает **состояние среды**, а не траекторию человека. Инверсия установлена, когда одна и та же организационная единица в два момента времени показывает разное расположение последствия. **Присутствие человека в двух разных средах инверсией не является и T4c не удовлетворяет.**

#### Разграничение T4a и T4c на нисходящих парах

Без ограничения области буквальные формулировки T4a и T4c дали бы на двух нисходящих парах один и тот же результат:

```
STP/STJ → STJ/STP        SFP/SFJ → SFJ/SFP
```

Причина: у нисходящей пары Сущность уже выше Феномена по стадии, поэтому «опустить Сущность на стадию и поднять бывшую Сущность в Феномен» совпадает с «поменять позиции местами».

**Разрешение — подтверждено автором:** область применения T4a ограничена восходящими парами; на нисходящих парах действует только T4c.

Это ограничение устраняет **вырождение**: два механизма перестают давать один и тот же результат из одной среды при неразличимых основаниях.

> **Удалено в v1.7.** Здесь стояло утверждение: «При этом ограничении механизмы **не пересекаются ни на одной среде из девяти**. Вырождение устранено.» Второе предложение верно и сохранено. Первое **ложно и удалено**: ограничение области T4a разграничивает T4a и T4c, но ничего не говорит о T4b. Среда `NF/NT` получает определённый результат и по T4a (`→ NT/STJ`), и по T4b (`→ NF/SFJ`).
>
> По уточнению Владельца это **законное множественное следование при разных триггерах**, а не дефект. Устранение вырождения и отсутствие пересечения — разные утверждения; смешение их было ошибкой транскрипции.

#### Законное множественное следование из `NF/NT`

```
NF/NT + триггер T4a (эндогенный распад)          → NT/STJ
NF/NT + триггер T4b (демографическое замещение)  → NF/SFJ
```

Оба перехода законны. Они не конкурируют: у них разные триггеры, разные причины и разный темп.

Первичный источник независимо свидетельствует о самой развилке из `NF/NT` — `[СТ-7, ¶634]`:

> «Решения о том, как именно будет использована новая идея, принимаются не теми, кто ее создал, а теми, у кого больше материальных ресурсов, силы и власти. Иными словами, одна и та же идея, рожденная в среде **NF/NT**, может быть реализована по-разному в средах **NF/SFJ** и **NT/STJ** — в зависимости от того, **кто обладает инструментами для ее воплощения**.»

**Границы этого свидетельства — читать внимательно.**

Источник говорит о **реализации идеи**, рождённой в `NF/NT`, в двух других средах, и называет различающий признак: обладание инструментами воплощения. Источник **не утверждает**, что это переход самой среды `NF/NT` в другую среду, и **не отождествляет** этот признак с триггерами T4a или T4b.

Поэтому цитата фиксируется как:

- `PRIMARY SOURCE STATEMENT` — из `NF/NT` расходятся именно две названные среды, `NF/SFJ` и `NT/STJ`, и расхождение управляется внешним условием;
- **не** как источниковое подтверждение того, что триггерами являются эндогенный распад и демографическое замещение.

Соответствие «обладание инструментами воплощения ↔ триггеры T4a/T4b» **не установлено** и вынесено в открытые позиции. Его установление — предмет отдельного авторского решения, а не транскрипции.

#### T4-S · Источниковый контекст · линия формирования сред

> **Внесено в v1.7 как ИСТОЧНИКОВЫЙ КОНТЕКСТ.** Это не новый механизм и не следствие. Это фиксация того, что первичный источник описывает **собственную линию формирования сред**, направление которой — **восходящее**. Раздел внесён, чтобы верификатор располагал источниковой опорой T4 и мог отличить источниковое утверждение от транскрипторской реконструкции.

`[СТ-7, ¶598 и далее]`, раздел «Бессознательная психическая подстройка под среду взаимодействия. Развитие и деградация личности», отвечает на поставленный там же вопрос «как происходит процесс формирования и объединения различных типов сред взаимодействия?».

**Порождение S-пар** — `[СТ-7, ¶615]`: среда `SJ/SP` формируется структурами `SFP` либо `STP`; при сущности `SFP` феноменологическое проявление есть `SFJ`, при сущности `STP` — `STJ`. Связующее звено — предпочтение F либо T соответственно.

**Восходящая линия** — `[СТ-7, ¶622, ¶624]`, механизм назван «через связывающее предпочтение»:

```
SFJ/SFP → NF/SFJ      «Так формируется среда NF/SFJ»
STJ/STP → NT/STJ      «Так из среды STJ/STP формируется среда NT/STJ»
```

**Объединение с условием** — `[СТ-7, ¶628]`:

```
NF/SFJ → NF/NT
NT/STJ → NF/NT
```

> «Возможно ли объединение сред NF/SFJ и NT/STJ? Безусловно, **но только если представители этих сред способны взаимодействовать на уровне теоретического или специализированного сознания**. В этот момент происходит переход от сред NF/SFJ или NT/STJ к среде взаимодействия NF/NT.»

Это **источниковый триггер восходящего перехода**: способность представителей взаимодействовать на уровне теоретического или специализированного сознания. Он записан в источнике явно и в этом отношении сильнее обеспечен, чем триггеры T4a и T4b.

#### Что здесь НЕ утверждается

Настоящий раздел **не** объявляет T4-S четвёртым механизмом, **не** включает его в область T4a/T4b/T4c и **не** порождает новых переходов сверх перечисленных в T4a, T4b, T4c.

В частности, транскриптор фиксирует наблюдение и **не превращает его в утверждение**:

> Множество рёбер восходящей линии T4-S и множество рёбер нисходящей таблицы T4a совпадают, будучи пройдены в противоположных направлениях.

Совпадение множеств рёбер есть **наблюдение над двумя таблицами**. Утверждение «эти рёбра обратимы» или «T4a есть обращение линии формирования» в первичном источнике **отсутствует** и автором в этой сессии **не подтверждалось**. Такое утверждение было бы новой аксиоматической добавкой.

**Статус.** `SOURCE OBSERVATION / NOT A MECHANISM / REQUIRES OWNER DECISION` — вопрос об обратимости вынесен в открытые позиции.

### T5 · Захват обёртки

Внешнее событие. Феномен сохраняется, Сущность заменяется извне.

**Слияние структурно есть захват обёртки, а не сложение сред.** T4a и T4b происходят без сделки, сами; T5 приходит извне транзакцией.

**Область включает сращивание внутри S-слоя.** Слияние криминальной среды с аппаратом исполнительной власти есть T5, а не четвёртый механизм: две среды приходят к общей оболочке — криминал получает институциональную защиту, институт получает криминальную свободу, — и обе формы сосуществуют под одним удержанным Феноменом. Отдельного механизма для этого случая не требуется.

**Разграничение с T4b.** Совпадают по форме — Феномен удерживается, Сущность замещается, — но различны по причине и темпу: T4b идёт изнутри численностью за десятилетия, T5 приходит извне транзакцией.

### T6 · Поглощение как исход по умолчанию

Три структурных исхода объединения:

| Исход | Структурное требование |
|---|---|
| **(a) Поглощение** — A подчиняет сущность B | **ничего** |
| **(b) Карман** — расхождение сущностей удерживается границей | **именованный держатель границы** в A с властью её удерживать |
| **(c) Рождение новой НС** | **творцы рефлексивного уровня с обеих сторон, сохранённые** (по A3) |

Поглощение наступает само. Два других требуют конкретных, называемых, до-сделочных обеспечений — и это проверяется на T0.

### T7 · Направление поглощения

По **H-A4** операбельное пересечение двух сред есть низшая стадия: субъекты низшего уровня не оперируют правилами высшего, обратное возможно.

**Сущностью результата становится более низкая стадия. Более высокая выживает только как Феномен.**

> **Уточнено в v1.7.** Ранее T7 выводился «по A4». После ослабления A4 до источниковой формулировки о последовательности уровней (§2) T7 опирается на гипотезу **H-A4**, а не на аксиому, и наследует её статус. Из A4 в её нынешнем виде T7 **не следует**.

### T8 · Стиль как правило доступа

Стиль управления управляет преобразующим свойством НС, то есть тем, кому позволено создавать новые нормы.

> **Исправлено в v1.7 по первичному источнику.** Таблица ниже приведена в соответствие со строкой «Уровни освоения НС всеми её субъектами» в четырёх главах `[НС]`. Формулировка v1.6 по бюрократическому стилю — «никто — вакансия, правят функционеры» — **ложна относительно источника** и удалена.

| Стиль | Кто получает рефлексивный доступ | Источник |
|---|---|---|
| Авторитарный | только высшее руководство — монополия | `[НС, с. 40]` «Рефлексивный — **только для высшего руководства**» |
| Бюрократический | руководство и официальные эксперты в санкционированных руководством проектах | `[НС, с. 42]` «Рефлексивный — **для руководства и официальных экспертов**, участвующих в санкционированных руководством проектах» |
| Конкурентный | руководители и победители конкуренции | `[НС, с. 46]` «Рефлексивный — **только у руководителей и победителей**» |
| Коллегиально-экспертный | все субъекты, задействованные в развитии НС | `[НС, с. 43]` «Рефлексивный и ролевой **для всех субъектов**, задействованных в процессе развития НС» |

**Наблюдение, следующее из исправленной таблицы:** рефлексивный доступ при всех четырёх стилях предоставляется **кому-то**. Стили различаются не наличием доступа, а **широтой его распределения**.

**Стиль определяет, произойдёт ли деградация. Среда определяет, куда она пойдёт.**

Ортогональность стиля и среды, заявленная в `COMBINATION_RULE`, получает основание: среда говорит, за что идёт борьба; стиль — кому позволено менять её правила.

### T9 · Условие достижимости исхода (c)

> **Переписан в v1.7 — контролирующее уточнение Владельца.** Формулировка v1.6 «**у неё нет и не будет творцов**» **удалена**. Она противоречила собственной строке T8 об авторитарной монополии и противоречит первичному источнику, где рефлексивный доступ есть при всех четырёх стилях. Владелец уточняет: творцы на вершине существовать могут; ограничение состоит в отсутствии **распределённой** рефлексивной способности ниже вершины.

Исход (c) — рождение новой НС — по T6 требует творцов рефлексивного уровня **с обеих сторон, сохранённых**. T9 отвечает на вопрос, при каких стилях это структурно достижимо.

#### Четыре различаемых понятия

T9 опирается на различение, которое в v1.6 было смазано. Эти четыре понятия **не синонимы**:

1. **Наличие творцов** — есть ли в организации хоть один субъект рефлексивного уровня.
2. **Распределение рефлексивного доступа** — у скольких субъектов и на каких условиях он есть.
3. **Наличие общего рефлексивного пространства** — допущены ли субъекты рефлексивного уровня обеих сторон к совместному созданию новой нормы.
4. **Отношение к трансформации НС** — что организация делает с предложением новой нормы, когда оно поступает.

Исход (c) определяется пунктами **3 и 4**, а не пунктом 1.

#### Разбор по стилям

Различающая опора — строка `Отношение к трансформации НС` первичного источника, а не строка уровней доступа.

**Авторитарный.** Рефлексивный доступ монополизирован вершиной `[НС, с. 40]`. Творцы **не объявляются отсутствующими**. Ограничение — отсутствие распределённого рефлексивного пространства, при котором новая норма могла бы создаваться совместно. Источниковая опора по отношению к трансформации, `[НС, с. 39]`: «Явное и неявное блокирование любого нового процесса в организации в пользу сохранения привычного и понятного контекста. Недоверие и отвращение к людям, являющимся драйверами развития организации».

**Бюрократический.** Рефлексивный доступ существует — у руководства и официальных экспертов `[НС, с. 42]`. Но наличие доступа само по себе **не открывает исход (c)**: источник фиксирует процедурную подмену развития приспособлением, `[НС, с. 42]`: «Формализация творческих предложений, апелляция к внешним авторитетам, **замена смысла развития на адаптацию** — подстройка под текущую ситуацию с минимальным риском для руководителей».

**Коллегиально-экспертный.** Рефлексивный и ролевой уровень — для всех субъектов, задействованных в развитии НС `[НС, с. 43]`; отношение к трансформации: «Индивидуальное и межгрупповое творчество как основной драйв в развитии НС. Новые решения приветствуются и реализуются в рамках достигнутых компромиссов» `[НС, с. 43]`. Наиболее полное соответствие условиям исхода (c) из четырёх стилей.

**Конкурентный — ЧАСТИЧНО ОТКРЫТ.** Рефлексивный доступ есть у руководителей и победителей `[НС, с. 46]`, то есть распределён шире вершины, но обусловлен результатом. Отношение к трансформации ограничено инструментально, `[НС, с. 45]`: «Новые идеи принимаются только в случае, если они напрямую **усиливают конкурентоспособность** продукта или команды».

Конкурентный стиль **не классифицируется ни как открытый, ни как закрытый**. Новая норма допускается, но только та, что проходит инструментальный фильтр; норма, не усиливающая конкурентоспособность, отсекается независимо от наличия творцов.

#### Формулировка T9

**Исход (c) требует общего рефлексивного пространства, в котором творцы обеих сторон допущены к совместному созданию новой нормы и сохранены после сделки.**

- При **авторитарном** стиле хотя бы одной стороны общего рефлексивного пространства нет: доступ монополизирован вершиной, а трансформация блокируется. Достижимы поглощение либо карман.
- При **бюрократическом** стиле рефлексивный доступ есть, но развитие процедурно подменяется адаптацией. Исход (c) **не считается доступным по умолчанию** на одном лишь основании наличия доступа.
- При **коллегиально-экспертном** стиле условия исхода (c) выполнимы.
- При **конкурентном** стиле исход (c) **частично открыт**: достижим для норм, усиливающих конкурентоспособность, и недостижим для прочих.

Проверяется до закрытия, по документам, без обращения к исходу.

> **Статус.** `EMPIRICAL/THEORETICAL HYPOTHESIS`. Строки таблиц стилей — `PRIMARY SOURCE STATEMENT`. Перенос со стиля управления НС внутри одной организации на структурный исход объединения двух организаций — `OWNER INTERPRETATION`, эмпирически не установленный.

### T11 · Природа разрыва

**Восходящий разрыв** (Сущность ниже Феномена) есть **унаследованный самообман** среды: она верит собственному феномену.

**Нисходящий разрыв** (Сущность выше Феномена) есть **спроектированная конструкция** для привлечения.

Практическое различие: восходящий разрыв закрывается предъявлением зеркала, нисходящий — нет, потому что он и есть инструмент.

Продолжение T2. Подтверждается собственными формулировками автора в TED Q18: «**aspirational** gap» для восходящего NF/SFJ и «narrative **designed** to manage acquirer perception» для нисходящего STP/STJ.
