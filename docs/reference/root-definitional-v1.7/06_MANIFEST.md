## 5. ВНЕШНИЕ ЗАВИСИМОСТИ

Оракул подсчёта якорей **закрыт автором в v1.4**: счёт ведётся по субъекту диагностики, конвенция дедупликации не требуется. См. `03` раздел 4.

**В v1.7 открытые позиции появились вновь.** Утверждение v1.6 «открытых вопросов к автору не осталось» **снято**. Открыты и требуют отдельного авторского решения:

- обратимость рёбер линии формирования `T4-S` относительно нисходящей таблицы `T4a`;
- соответствие источникового признака «кто обладает инструментами воплощения» триггерам `T4a` / `T4b`;
- приоритет между `T4a`, `T4b`, `T4c`;
- содержательное разрешение равного `argmax` в `T4b`;
- окончательная классификация `TED Q17, Q9, Q12, Q14`;
- скорируемый либо нескорируемый вариант наблюдения расхождения;
- статус `H-A4` и, через неё, статус `T7`.

Объект корневой проверки определён, но **не замкнут**: перечисленное подлежит решению Владельца, а не восполнению транскриптором.

Трассировка в файле `03` действительна только для:

```
questionnaires.json
SHA-256  b8b36cc2a9b552830882538b144be0f795f703ad0d82157f585d7c83524d4713
```

Authority-стек в пакет **не включён**. Ожидается, что верификатор располагает им из паков `CASE-3.4.CORR1 / CORR2 / CORR3`; суммы совпадают.

Первичные источники модели (книги «Структурная типология» 2024 и «Теория Нормативная ситуация» 2025, презентация «Трехбуквенный код ч.3/4» от 09.05.2026) в пакет **не включены** — они у Владельца. Для восстановления исходных определений верификатору потребуется доступ к ним.

> **Локализованы в v1.7.** Аудит v1.6 не нашёл двух книг и вернул `NOT DETERMINABLE` по источниковой верности A1–A4 и по популяционной посылке T4b. Обе книги находятся **вне репозитория проекта**, на локальном рабочем столе Владельца. Пути, обозначения и постраничные локаторы внесены в `02_ST_ENVIRONMENT_AXIOMATICS_v0.1.md` §0.
>
> Локаторы просмотрены транскриптором физически, но это **не заменяет независимой сверки**: сверку выполняет верификатор. Наличие локатора в пакете не есть подтверждение верности транскрипции.
